# Security Policy

## Supported Unity Versions

| Version | Supported |
| ------- | --------- |
| 6.x | :white_check_mark: |
| 2022.3 | :white_check_mark: |
| < 2022.3 | :x: |

## Reporting a Vulnerability

Report it privately through **Security > Report a vulnerability** on this repository, so it isn't public before it's fixed. Things like text that crashes or freezes the filter, or a way around `[PurrFiltered]` on the server, belong here.

A word that slips through the filter isn't a vulnerability, open an issue or a pull request against `dev` with it instead.
